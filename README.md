# 🌌 Predicting Potentially Hazardous Asteroids

A Machine Learning model to identify and classify potentially hazardous asteroids based on NASA orbital and physical characteristics.

---

### 📊 **Project Overview**
- **Domain:** Machine Learning & Data Science
- **Models Used:** Random Forest, XGBoost
- **Dataset:** NASA Asteroid Dataset

---

### 🛠️ **Workflow**
1. **Data Preprocessing & Cleaning:** Handling missing values and feature scaling.
2. **Exploratory Data Analysis (EDA):** Insights into orbital parameters and size distributions.
3. **Model Training & Evaluation:** Training Random Forest and XGBoost classifiers for hazard prediction.
